# FastFurnace

「相対的時空間かまど」を追加する Paper プラグインです。
オフハンドにかまど、メインハンドにアイテムを持って右クリックするだけで、燃料の供給と精錬が一瞬で終わります。

## 動作環境

- Paper 1.15.2
- Java 8 以上
- 以下のプラグイン
  - StorageBox
  - [mcMMO](https://github.com/mcMMO-Dev/mcMMO)
  - ItemStash

## 使い方

1. `/fastfurnace` で相対的時空間かまどを入手します。
2. かまどをオフハンドに持ちます。
3. メインハンドに燃料か精錬したいアイテムを持って右クリックします。

| 操作 | 動作 |
| --- | --- |
| 右クリック | 1個だけ燃料にする / 精錬する |
| スニーク + 右クリック | まとめて燃料にする / 精錬する |

- 燃料の残量はかまどの名前の `(数字)` に表示されます。精錬1個につき燃料を1消費します。
- まとめて精錬できるのは1回64個までです。出来上がるアイテムの StorageBox がインベントリにあれば、上限なしで精錬して StorageBox に入れます。
- マグマバケツをまとめて燃料にするときも同様に、空バケツの StorageBox がなければ64個までです。
- StorageBox を手に持って使うこともできます。
- 精錬すると mcMMO の精錬スキル経験値が入ります。スキルレベルに応じて、出来上がるアイテムが倍になることがあります。
- インベントリに入りきらなかったアイテムは ItemStash に送られます。
- 名前や説明文の付いたアイテムは精錬できません。

## コマンド・権限

| コマンド | 説明 | 権限 |
| --- | --- | --- |
| `/fastfurnace` | 相対的時空間かまどを入手する | `fastfurnace.admin` |

## 設定 (`config.yml`)

| キー | 説明 |
| --- | --- |
| `furnace-name` | かまどの名前。末尾に燃料の残量 `(数字)` が付きます |
| `furnace-lore` | かまどの説明文。配布済みのかまどにも、使ったときに反映されます |
| `fuels` | 燃料にできるアイテムと、1個あたりの燃料の量 |
| `use-vanilla-recipes` | サーバーに登録されている全てのかまどレシピで精錬できるようにするか |
| `give-vanilla-exp` | 精錬時に、普通のかまどと同じ量のバニラ経験値を付与するか (既定: `false`) |
| `disabled-smelting` | 精錬できないようにするアイテムの一覧 |
| `smelting` | レシピの個別設定。かまどレシピの結果や mcMMO 経験値を上書き・追加できます |

`smelting` の書き方:

```yaml
smelting:
  IRON_ORE:
    result: IRON_INGOT # 省略するとかまどレシピの結果
    xp: 25             # mcMMO の経験値 (1個あたり)。省略するとバニラのレシピの経験値
```

アイテム名は Bukkit の `Material` の名前 (例: `IRON_ORE`)で指定します。

## ビルド

JDK 17 以上で Gradle を実行してください (ビルドされる jar は Java 8 向けです)。

```bash
./gradlew build
```

`build/libs/` に jar が出力されます。
